# 콘솔 RPG 프로젝트

## 프로젝트 소개
C# 콘솔 환경에서 제작한 턴제 RPG 프로젝트입니다.  
플레이어가 직업을 선택하고 몬스터와 전투하며, 아이템, 장비, 상점, 퀘스트 시스템을 이용해 성장할 수 있도록 구현했습니다.

## 개발 목적
객체지향 프로그래밍을 활용하여 플레이어, 몬스터, 아이템, 전투, 상점, 퀘스트 기능을 클래스로 나누어 구현하는 것을 목표로 했습니다.

## 구현 기능
- 턴제 전투 시스템
- 플레이어 / 몬스터 클래스 구현
- 직업 선택 시스템
- 레벨업 및 경험치 시스템
- 장비 장착 시스템
- 인벤토리 시스템
- 상점 구매 / 판매 시스템
- 스테이지 및 보스 몬스터
- 희귀 몬스터 시스템
- 퀘스트 시스템
- 상태 이상(중독), 해독제, 엘릭서

## 클래스 구성
- `Program.cs` : 게임 전체 진행
- `Character.cs` : Character, Player, Monster
- `Item.cs` : 아이템 및 장비 관련 클래스
- `Inventory.cs` : 인벤토리 관리
- `Skill.cs` : 스킬 정보 관리
- `StageManager.cs` : 스테이지, 몬스터, 드랍 관리
- `BattleSystem.cs` : 전투 진행
- `ShopSystem.cs` : 상점 기능
- `QuestSystem.cs` : 퀘스트 관리

## 사용 기술
- C#
- .NET
- Git
- GitHub

## 실행 방법
1. 프로젝트를 실행한다.
2. 캐릭터를 선택한다.
3. 마을, 상점, 던전, 퀘스트를 이용하며 플레이한다.

## 느낀 점
이번 프로젝트를 통해 객체지향 방식으로 기능을 나누어 구현하는 연습을 할 수 있었습니다.  
기능이 많아질수록 클래스를 나누고 역할을 분리하는 것이 중요하다는 점을 배웠습니다.  
GitHub Desktop의 브랜치와 Pull Request 기능도 실습했습니다.  
새로운 기능과 프로그램을 배우는 과정이 신기했고, 재미있었습니다.
SourceTree를 이용한 Git 실습도 진행했습니다.
